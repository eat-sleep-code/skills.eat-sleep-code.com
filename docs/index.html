eat-sleep-code-react

Personal house style and conventions for React projects (Vite + Cloudflare Pages/Workers, Tailwind, react-router) — packaged as a Claude Skill.

This isn't a library or framework — it's a standing set of conventions (i18n structure, light/dark mode, accessibility, PWA setup, backend security patterns, a deployment checklist, and more) that Claude reads and applies automatically when helping build or edit a React project, so every project comes out consistent with the last one instead of re-deciding the same defaults each time.
